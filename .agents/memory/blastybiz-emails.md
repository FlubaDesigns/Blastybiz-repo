## Available mailboxes

- support@blastybiz.com
- billing@blastybiz.com
- noreply@blastybiz.com

**Why:** `hello@blastybiz.com` is NOT a real mailbox. Always use one of the above.
Current default from address in Cloud Functions and HTML: `info@blastybiz.com`.
