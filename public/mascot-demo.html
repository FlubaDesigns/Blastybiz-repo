Mascot component — portability proof

Two independent mascots on one page, each with its own name, mood and caption.

Instance A

Named “Blasty” · created from a selector

Instance B

Named “Scout” · same artwork, separate state

Both mascots are created with PBMascot.create(target, options). Clicking a mood on one leaves the other untouched — that is the point of the change. Each instance also gets its own copies of the artwork's internal gradient ids, so neither can steal the other's colours.
