Request Pages and Instagram permissions
Required for posting — needs Meta App Review for production
▼
1
In your Meta App → App Review → Permissions and Features
2
Request these permissions: pages_manage_posts, pages_read_engagement, instagram_basic, instagram_content_publish
3
While in Development Mode, only your own test Facebook accounts can connect — that's fine for testing
4
For production, submit for App Review with a screen recording showing how BlastyBiz uses each permission
Timeline: Meta App Review typically takes 5–14 business days. Start this early.
