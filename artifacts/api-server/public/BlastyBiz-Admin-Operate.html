Request Pages and Instagram permissions
Required for posting — needs Meta App Review for production
▼
1
In your Meta App → App Review → Permissions and Features
2
Request these permissions: pages_manage_posts, pages_read_engagement, instagram_basic, instagram_content_publish
3
While in Development Mode, only your own test Facebook accounts can connect — that's fine for testing
4
For production, submit for App Review with a screen recording showing how BlastyBiz uses each permission
Timeline: Meta App Review typically takes 5–14 business days. Start this early.

🗄️ Firebase Storage Setup required
Enable Firebase Storage and set CORS rules
Required for image uploads — the uploadImage function uses the default Storage bucket
▼
1
Open Firebase Console → Storage and click Get started (requires Blaze plan)
2
Choose Start in production mode → select region us-east1 (matches Firestore) → click Done
3
The default bucket (blastybiz-9523e.firebasestorage.app) is created automatically — no further config needed for the function
Current use: Only the uploadImage Cloud Function writes to Storage (server-side, no CORS needed). Storage costs are pay-per-GB and typically negligible for listing images.
🔧 Ongoing Operator Commands Reference
Deploy commands cheat sheet
Run in Replit Shell whenever you make changes
▼

Run these from the Replit Shell tab:

Deploy HTML pages (hosting)

npx firebase-tools deploy --only hosting

Deploy all functions (after saving secrets)

npx firebase-tools deploy --only functions

Deploy Firestore security rules

npx firebase-tools deploy --only firestore:rules

Deploy a specific function

npx firebase-tools deploy --only functions:functionName

View function logs

npx firebase-tools functions:log --only functionName
