🗄️ Firebase Storage Setup required
Enable Firebase Storage and set CORS rules
Required for image uploads — the uploadImage function uses the default Storage bucket
▼
1
Open Firebase Console → Storage and click Get started (requires Blaze plan)
2
Choose Start in production mode → select region us-east1 (matches Firestore) → click Done
3
The default bucket (blastybiz-9523e.firebasestorage.app) is created automatically — no further config needed for the function
Current use: Only the uploadImage Cloud Function writes to Storage (server-side, no CORS needed). Storage costs are pay-per-GB and typically negligible for listing images.

npx firebase-tools deploy --only functions:functionName

npx firebase-tools functions:log --only functionName
