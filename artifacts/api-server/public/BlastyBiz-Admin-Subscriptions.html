💰 Pricing Control

Sets the monthly and annual prices shown on the home page and creates/updates all four Square subscription plans automatically — no redeploy or secrets needed. Only run this once per price change — running it again creates duplicate plans in Square; delete the old ones in the Square Dashboard first if you need to reset pricing.

📦 Business Limits per Plan

Max number of businesses a user can create under each plan. Takes effect immediately — no redeploy needed.
