# Source cleanup audit — November 11, 2026

This is the cleanup list requested after the small section 6 fixes. GitHub issue #38 remains the completion tracker. This report does not authorize deleting customer data or claim that remaining cleanup is finished.

## Coverage and method

Reviewed the tracked repository inventory at Main `59b6011936b8997495bd7ad9cc683e421ee42c6e` and the section 6 working changes: 1,246 tracked files before these additions, including 159 public files, 47 Functions files, 125 tooling files, 15 legacy API workspace files, deployment/rules/workflow configuration, documentation and archived deliverables. Runtime entry points, HTML script links, backend exports, generators, rules, package/compiler references and release callers were traced. A whole-tree text scan covered 563 source/configuration/documentation files and 495 distinct literal references. Binary assets and ZIPs were catalogued as assets/archives, not treated as executable source or judged obsolete by filename alone.

The derived backend inventory now has 80 exports and 44 page-called endpoints. A missing page caller is not proof of dead code: callbacks, webhooks, workers, operator endpoints and external callers need separate evidence. This is a repository audit; it does not establish that historical cloud records or third-party callers no longer exist.

## Removed in the small fix

The Account page's unreachable upgrade popup and its alternate `startCheckout` / `closeUpgradeModal` functions were removed. Its hardcoded capacities and AI counts had diverged from the active plan page. The existing View Plans and Manage Subscription routes remain the owners. Plan display now projects configured prices and business capacity through the existing payment module; customer plan responses no longer include AI limits. Generated platform plan copy is updated through `scripts/sync-public-content.cjs`.

- Browser authority files generated from backend facts, schedule rules and business form definitions are required projections, not competing sources. Keep their generation and drift checks.
- Current HTML routes can be reached by navigation, emails and saved links. No page is classified as deletable solely because it has no inbound repository link.
- Imported photographs/design documents, mascot source and historical rollback archives need provenance checks before deletion; they are not obsolete executable code merely because they sit outside Hosting.

Implement cleanup in small batches with the owner identified above. For each batch, trace callers, remove or redirect the old path, retain the user action, run focused behavior checks and verify through the existing release path. Do not create a second completion checklist alongside #38.
